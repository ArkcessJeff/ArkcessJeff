## 🚀 Projects & Contributions  

### 🔹 **Cybersecurity Operations Lab**  
The **Cybersecurity Operations Lab** is an **ongoing project** designed to help **both beginners and experienced cybersecurity professionals** gain **new, relevant, and practical technical skills**. This lab provides hands-on experience with **real-world attack simulations, log analysis, and security monitoring**, preparing individuals for roles in **SOC operations, incident response, and threat hunting**.

#### Features:
- A fully virtualized **SOC lab** integrating **Splunk, Security Onion, Kali Linux, and pfSense Firewall** for **threat detection and monitoring**.  
- **Step-by-step attack simulations** covering techniques like **MITRE ATT&CK tactics, lateral movement, privilege escalation, and malware analysis**.  
- **Log collection and analysis** with SIEM platforms like **Splunk, Microsoft Sentinel, and Elastic Stack**.  
- **Network traffic monitoring** using **Zeek, Suricata, and Wireshark** to detect malicious activities.  
- **Scripting and automation** exercises leveraging **PowerShell, Python, and Bash** for security automation.  

### 🔹 **Threat Detection Engineering**  
- Created **custom detection rules and alerts** for **MITRE ATT&CK techniques** using **Splunk and Elastic Stack**.  
- Simulated **Red Team attacks** (e.g., **Kerberoasting, Pass-the-Hash, and Lateral Movement**) and analyzed logs for **defensive countermeasures**.  
- Implemented **endpoint security solutions** (EDR/XDR) for **real-time attack visibility and remediation**.
